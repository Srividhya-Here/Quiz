# Responsive Quiz App 🎯

An interactive and responsive quiz web application built using **HTML, CSS, and JavaScript** as part of **Task-3: Advanced Styling and JavaScript**.

## 🚀 Features
- Responsive design for **mobile, tablet, and desktop** using CSS Media Queries
- Interactive quiz with **timer (10 seconds per question)**
- Score calculation and detailed **answer summary**
- **API integration** to fetch dynamic data
- Clean and user-friendly UI

## 🛠️ Technologies Used
- HTML5
- CSS3 (Grid, Media Queries)
- JavaScript (DOM Manipulation, Events, Timers, Fetch API)

## 📱 Responsive Design
The layout automatically adjusts based on screen size:
- Mobile devices
- Tablets
- Desktop screens

## ⚙️ How It Works
1. Click **Start Quiz**
2. Answer 5 timed questions
3. View score and correct answers
4. Fetches real-time data from a public API
5. Retake the quiz anytime
